# KATADORI

`index.html` を Edge / Chrome で開くと使えます。インストール・サーバー・インターネット接続は不要です。画像を外部に送信しません。

1. 対象物と1円玉を同じ平面に置き、真上から撮影します。背景は無地で対象と明暗差があるものにしてください。
2. 「写真を選ぶ」で画像を開きます。
3. 写真を開くと自動トレースが選択されています。型にしたい物の内側をクリックすると、外周に緑の線が出ます。明暗と初期の境界値を自動判定します。
4. 線が合わない場合は「輪郭の拾い方」を動かしてください。対象をクリックし直さなくても自動で更新します。失敗時は前の線をオレンジで表示し、DXF保存を止めます。
5. 緑の線が合っていれば、写真の上の「次へ：1円玉でサイズ合わせ」を押します。円周上の離れた3点をクリックします。3点から求めた円がオレンジで表示されます。円が1円玉の縁に合っているか確認してください。
6. 幅・高さを確認して「実寸DXFを保存」を押します。

手動でなぞる場合は「手動でなぞる」を選び、3点以上置いて輪郭を閉じます。閉じた輪郭から手動に切り替えると描き直しになりますが「元に戻す」で復元できます。頂点の修正は「頂点を移動」を選びます。

「サンプルで試す」では1円玉の円周上の3点は、例えば画像座標 (765,470)、(815,420)、(865,470)、対象の外寸は88 × 76 mmです。

## 仕様と制約

- DXF：AutoCAD R12（AC1009）、閉じた2D POLYLINE + VERTEX。座標値はmm（1図面単位 = 1 mm）。R12にはINSUNITSがないため、挿入・読み込み時の単位はmmに設定してください。型の左下が原点、Y軸は上向き。写真と1円玉は出力しません。
- 外周1個に対応。穴・複数パーツ・曲線エンティティは未対応。曲線は直線の集合になります。
- 自動抽出は明暗のしきい値による連結領域の外周です。AIによる物体認識や1円玉の自動検出ではありません。模様・影・背景への接触で誤抽出する場合は手動でなぞってください。
- 読み込み画像は最大辺2200 px、自動抽出は最大辺1200 pxに縮小します。拡大表示しても元の精度は増えません。
- 斜め撮影・高さの違い・レンズ歪みは補正しません。1円玉と対象の高さを揃え、加工前に実物との寸法確認をしてください。
- ページを閉じると写真・編集内容は消えます。作業完了時にDXFを保存してください。
- 1円玉直径の根拠：[造幣局](https://www.mint.go.jp/150th/essay/essay_data03)。DXF形式：[Autodesk LWPOLYLINE](https://help.autodesk.com/cloudhelp/2018/ENU/AutoCAD-DXF/files/GUID-748FC305-F3F2-4F74-825A-61F04D757A50.htm)。
